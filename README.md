# SharpMinds Website

This repository contains the static website for Sharpminds.work, a company offering modern IT solutions. The website is designed to be responsive and informative, showcasing the company's services and providing contact information.

## Website Structure

The website consists of the following main sections:

- **Header/Navigation**: Contains the company logo ("Sharpminds.work") and navigation links to "About Us," "Services," and "Contact Us."
- **Hero Section**: A prominent section with a compelling headline, a brief description of the company's offerings, and call-to-action buttons for "Our Services" and "Get in Touch."
- **About Section**: Provides more detailed information about Sharpminds.work, highlighting their expertise in modernizing technology stacks, optimizing workflows, and integrating mission-critical applications.
- **Services Section**: Outlines the core services offered, including:
    - Process Automation
    - System & API Integration
    - Cloud & Architecture Support
- **Contact Section**: Features a call to action to streamline tech stacks and provides an email address for inquiries.
- **Footer**: Contains copyright information for Sharpminds.work.

## Technologies Used

- HTML5 for structure
- CSS3 for styling

## Styling

The `style.css` file defines the visual presentation of the website, utilizing CSS variables for consistent theming. Key styling aspects include:

- **Responsive Design**: Adapts to different screen sizes, with specific adjustments for smaller mobile screens (e.g., navigation menu hidden).
- **Color Palette**: Uses a primary blue color (`--primary`) for highlights and action elements, along with a neutral palette for text and backgrounds.
- **Typography**: Employs a modern sans-serif font stack.
- **Component Styling**: Specific styles for buttons, navigation, section titles, service cards, and the contact box, ensuring a clean and professional look.

## How to View

To view the website, open `index.html` in a web browser.
